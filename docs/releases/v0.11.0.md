# WAIRC-2026 v0.11.0

This release adds an explicit complete-receiver control to the synthetic
robustness protocol without changing the competition data or submission
contracts.

## Highlights

- `robustness-small` now covers ten controlled conditions, including
  `all-nodes-present` alongside the periodic missing-node baseline and
  dedicated single-node absence checks.
- The redistributable `benchmark-fixture-v1` manifest records the ten controls
  and pins the updated deterministic report signature without distributing raw
  IQ, generated model artifacts, external recordings, or private labels.

## Compatibility

The new condition uses the existing synthetic missing-node semantics: every
test sample has all three receiver nodes present, with the default noise and
other controls. It does not intentionally change the 0..8 label mapping,
interleaved IQ parsing, missing-node handling, `stft-v1`, training, inference,
checkpoint fields, or submission serialization. The condition and signature
are synthetic reproducibility checks, not real-data benchmarks or competition
scores.
