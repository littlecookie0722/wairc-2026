# WAIRC-2026 v0.13.0

This release adds a lightweight environment doctor for local runtime checks
without changing the competition data or submission contracts.

## Highlights

- `wairc doctor` reports Python, Torch, Torchvision, CUDA availability, and the
  installed package version without reading competition data or starting a
  training job.
- Human-readable output is available for local troubleshooting and
  `doctor-v1` JSON output is available for scripts and CI tooling.
- Structured import failures expose an exception type without copying local
  environment paths or exception messages into the report.

## Compatibility

The doctor command is read-only. Existing `src.*` entry points and the
competition data schema, 0..8 label mapping, interleaved IQ parsing,
missing-node semantics, `stft-v1`, fold splitting, threshold search, ensemble
weighting, checkpoint fields, and submission serialization remain unchanged.

CUDA availability is an environment observation, not a claim that a training
run or full-dataset inference has been performed. The repository's automated
verification remains data-free and CPU-oriented; competition data and trained
checkpoints are not distributed.

## External assets

Competition data, trained checkpoints, generated caches, and private test
labels are not included. Users must obtain restricted assets through their
original channel and follow the applicable terms. Dependencies retain their
own licenses.
