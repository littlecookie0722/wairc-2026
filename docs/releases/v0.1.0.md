# WAIRC-2026 v0.1.0

The first public engineering release packages the existing multi-node RF IQ
classification workflow as an installable Python project while preserving its
competition compatibility boundaries.

## Highlights

- Unified `wairc` command-line entry point for the existing training,
  inference, rule-search, and submission-validation modules.
- Deterministic synthetic CPU demonstration covering IQ generation, STFT
  feature extraction, lightweight training, inference, submission writing,
  and validation without competition data.
- Synthetic regression tests, smoke testing, Ruff checks, distribution builds,
  and GitHub Actions CI.
- Architecture, reproducibility, contribution, security, roadmap, and release
  documentation.
- MIT license for the repository software.

## Compatibility

This release does not intentionally change the 0..8 label mapping, interleaved
IQ parsing, missing-node handling, STFT defaults, fold splitting, checkpoint
metadata, inference rules, ensemble weighting, or submission text format.

## Verification

The release candidate passed 17 CPU tests, Ruff, the data-free model smoke
test, Python bytecode compilation, dependency consistency checks, the installed
`wairc demo` workflow, and source/wheel distribution builds.

The synthetic demo result is a functional test only. It is not a real-data
benchmark, competition score, or adoption claim.

## External assets

Competition data and trained checkpoints are not included. Users must obtain
data through the original competition channel and comply with its terms.
PyTorch, torchvision, pretrained weights, and all other dependencies retain
their own licenses and terms.
