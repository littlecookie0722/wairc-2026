# WAIRC-2026 v0.15.0

This release adds versioned provenance for single-model validation predictions
without changing training selection or competition inference behavior.

## Highlights

- Single-model training writes `validation-predictions-v1` metadata alongside
  the historical `probs` and `labels` arrays.
- The artifact records validation sample IDs, best epoch, selection metric,
  metric value, class count, schema, and artifact type.
- `wairc artifact inspect|validate` accepts both the versioned artifact and
  historical files containing only `probs` and `labels`.
- `wairc artifact validate-run` checks class, epoch, and metric linkage while
  leaving `artifact-index-v1` coverage unchanged for backward compatibility.

## Compatibility

The `best_val_probs.npz` filename and historical array names and dtypes remain
unchanged. Validation splitting, loader order, model training, checkpoint
selection, probability generation, threshold search, and submission behavior
are unchanged. Existing `src.*` entry points, the competition data schema,
0..8 label mapping, interleaved IQ parsing, missing-node semantics, `stft-v1`,
fold splitting, ensemble behavior, inference rules, checkpoint fields, and
submission serialization remain unchanged.

The automated verification is data-free and CPU-oriented. It does not claim a
competition score, GPU training result, or full-dataset inference result.

## Verification

## External assets

Competition data, trained checkpoints, generated caches, and private test
labels are not included. Users must obtain restricted assets through their
original channel and follow the applicable terms. Dependencies retain their
own licenses.
