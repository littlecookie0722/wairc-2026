# WAIRC-2026 v0.5.0

This release completes the first public synthetic benchmark maintenance loop:
machine-readable reports, compact review summaries, and controlled robustness
conditions that remain separate from real-data performance claims.

## Highlights

- `wairc benchmark summarize <report>` validates `benchmark-report-v1` and
  renders a compact Markdown table with relative artifact names and the
  deterministic signature.
- `robustness-small` now evaluates six fixed test conditions: baseline,
  higher noise, node-0 absence, a 180 Hz frequency offset, a 32-sample timing
  offset, and a 0.5 signal gain.
- The clean training split and default synthetic demo remain unchanged; the
  perturbations apply only to the controlled synthetic test conditions and are
  recorded in the benchmark manifest.

## Compatibility

This release does not intentionally change the 0..8 label mapping, interleaved
IQ parsing, missing-node semantics, `stft-v1` behavior, fold splitting,
threshold search, ensemble weighting, checkpoint consumption rules, or
submission text format. Existing `src.*` entry points and the v0.4.0 public
adapter/SigMF paths remain available.

## Verification

The release candidate is required to pass the local test suite, data-free smoke
test, Ruff, bytecode compilation, both benchmark profiles and the summary CLI,
source and wheel builds, and the GitHub Actions Python 3.10/3.11/3.12 matrix,
including the Python 3.12 package and isolated-wheel checks.

Synthetic metrics are functional checks on generated data only. They are not
real-data benchmarks, competition scores, or adoption claims. GPU training and
full-data inference remain manual checks because competition data and trained
models are not distributed with the project.

## External assets

Competition data, trained checkpoints, generated caches, and private test
labels are not included. Users must obtain restricted assets through their
original channel and follow the applicable terms. Dependencies retain their
own licenses.
