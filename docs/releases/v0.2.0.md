# WAIRC-2026 v0.2.0

This release adds a versioned foundation for reproducible training and
inference artifacts while preserving the competition pipeline's established
compatibility boundaries.

## Highlights

- `run-manifest-v1` records sanitized Git, runtime, transform, model, training,
  command, and output provenance for training workflows.
- `dataset-fingerprint-v1` links a run to normalized dataset metadata and
  referenced file content without recording local paths, filenames, sample IDs,
  or raw IQ values.
- `checkpoint-v1`, `oof-v1`, `rule-v1`, and `cache-v1` provide explicit metadata
  and validation for model, OOF, inference-rule, and STFT cache artifacts.
- Legacy unversioned checkpoints, OOF files, inference rules, and compatible
  STFT caches remain readable through compatibility loaders.
- Focused regression tests, synthetic CPU checks, and CI coverage run on
  Python 3.10, 3.11, and 3.12. The release pipeline also builds distributions
  and verifies an installed wheel from an isolated directory.

## Compatibility

This release does not intentionally change the 0..8 label mapping, interleaved
IQ parsing, missing-node semantics, `stft-v1` behavior, fold splitting,
threshold search, ensemble weighting, checkpoint consumption rules, or
submission text format. New cache files use `cache-v1`; older `x/node_mask`
caches remain readable when their shape is compatible.

## Verification

The release candidate passed the local test suite, smoke test, Ruff, bytecode
compilation, CLI checks, source/wheel builds, isolated installation, `pip check`,
and the GitHub Actions Python 3.10/3.11/3.12 matrix on the release commit.

The synthetic demo is a functional workflow check only. It is not a real-data
benchmark, competition score, or adoption claim.

## Follow-up

Artifact inspection CLI commands, generic dataset adapters, optional SigMF
import, synthetic benchmark fixtures, and robustness profiles remain planned
follow-up work. They are not part of this release.

## External assets

Competition data, trained checkpoints, generated caches, and private test
labels are not included. Users must obtain restricted assets through their
original channel and follow the applicable terms. Dependencies retain their
own licenses.
