# WAIRC-2026 v0.14.0

This release adds versioned provenance for aggregate out-of-fold probabilities
without changing the competition ensemble or inference behavior.

## Highlights

- Rule search writes `oof-aggregate-v1` metadata alongside the historical
  `probs`, `labels`, and `sample_ids` arrays.
- Mean and tag-weighted aggregates record their method, normalized weights,
  class count, and path-free source filenames.
- `wairc artifact inspect|validate` recognizes both versioned aggregates and
  earlier unversioned `*.oof_probs.npz` files.

## Compatibility

The aggregate output filename and historical array names and dtypes remain
unchanged. The implementation continues to use the existing mean and
tag-weighted probability formulas before running the same threshold search.
Existing `src.*` entry points, the competition data schema, 0..8 label mapping,
interleaved IQ parsing, missing-node semantics, `stft-v1`, fold splitting,
inference rules, checkpoint fields, and submission serialization remain
unchanged.

The automated verification is data-free and CPU-oriented. It does not claim a
competition score, GPU training result, or full-dataset inference result.
