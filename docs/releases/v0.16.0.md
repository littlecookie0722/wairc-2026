# WAIRC-2026 v0.16.0

This release adds content-addressed integrity checks for single-model
validation probabilities without changing their values or the competition
workflow.

## Highlights

- `artifact-index-v2` covers manifest-declared checkpoints, OOF files,
  inference rules, and validation probabilities.
- Single-model training writes v2 indexes so `wairc artifact validate-run`
  detects size or SHA-256 changes to `best_val_probs.npz`.
- V2 validates the validation artifact type and
  `validation-predictions-v1` schema in addition to its existing manifest
  linkage checks.
- K-fold training and the default artifact-index finalizer continue to write
  `artifact-index-v1` with its exact historical coverage.

## Compatibility

Existing `artifact-index-v1` and no-index `run-manifest-v1` files remain valid.
Unknown artifact-index schemas are rejected. Training, validation splitting,
probability values, checkpoint selection, threshold search, ensemble behavior,
and submission behavior are unchanged. Existing `src.*` entry points, the
competition data schema, 0..8 label mapping, interleaved IQ parsing,
missing-node semantics, `stft-v1`, fold splitting, inference rules, checkpoint
fields, and submission serialization remain unchanged.

The automated verification is data-free and CPU-oriented. It does not claim a
competition score, GPU training result, or full-dataset inference result.
