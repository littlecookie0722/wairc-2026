# WAIRC-2026 v0.4.0

This release adds the first reusable RF sample/data interoperability paths and
data-free benchmark profiles while preserving the competition pipeline's
established compatibility boundaries.

## Highlights

- Stable `complex_iq_to_spectrogram` support for native one-dimensional complex
  arrays with exact equivalence to the existing interleaved-IQ `stft-v1` path.
- Public `RFNode`/`RFSample` contracts, `RFDatasetAdapter`, an in-memory
  `SyntheticDatasetAdapter`, and a strict lazy three-node CSV/NPZ adapter.
- Experimental, read-only SigMF metadata parsing and one-recording import for
  the supported complex single-channel subset.
- `wairc benchmark run --profile cpu-smoke` writes
  `benchmark-manifest-v1` and `benchmark-report-v1` records with deterministic
  signatures.
- `wairc benchmark run --profile robustness-small` evaluates baseline,
  higher-noise, and node-0-missing synthetic test conditions with per-condition
  metrics.

## Compatibility

This release does not intentionally change the 0..8 label mapping, interleaved
IQ parsing, missing-node semantics, `stft-v1` behavior, fold splitting,
threshold search, ensemble weighting, checkpoint consumption rules, or
submission text format. Existing `src.*` entry points remain available, and
the new adapter/API paths are additive. The SigMF path remains explicitly
experimental and does not map annotations into competition labels.

## Verification

The release candidate is required to pass the local test suite, data-free smoke
test, Ruff, bytecode compilation, both synthetic benchmark profiles, source and
wheel builds, and the GitHub Actions Python 3.10/3.11/3.12 matrix, including
the Python 3.12 package and isolated-wheel checks.

Synthetic metrics are functional checks on generated data only. They are not
real-data benchmarks, competition scores, or adoption claims. GPU training and
full-data inference remain manual checks because competition data and trained
models are not distributed with the project.

## External assets

Competition data, trained checkpoints, generated caches, and private test
labels are not included. Users must obtain restricted assets through their
original channel and follow the applicable terms. Dependencies retain their
own licenses.
