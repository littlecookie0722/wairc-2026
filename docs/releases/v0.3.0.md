# WAIRC-2026 v0.3.0

This release adds read-only artifact inspection and content-addressed run
integrity checks on top of the versioned reproducibility foundation introduced
in v0.2.0.

## Highlights

- `wairc artifact inspect` and `wairc artifact validate` detect and validate
  versioned or supported legacy checkpoint, OOF, inference-rule, and STFT cache
  artifacts with path-redacted human or JSON summaries.
- `wairc artifact validate-run` resolves manifest-declared filenames inside the
  run directory, validates linked artifact types and public metadata, and
  checks rule-to-OOF source linkage.
- Newly completed training manifests include an optional `artifact-index-v1`
  block for declared checkpoints, OOF files, and rules. It records path-free
  SHA-256 digests, byte sizes, artifact types, schemas, folds, and tags.
- Run validation checks exact index coverage and detects changes to indexed
  content or metadata. Existing manifests without an index remain valid.

## Compatibility

This release does not intentionally change the 0..8 label mapping, interleaved
IQ parsing, missing-node semantics, `stft-v1` behavior, fold splitting,
threshold search, ensemble weighting, checkpoint consumption rules, or
submission text format. Existing `src.*` entry points and supported legacy
artifact loaders remain available.

## Verification

The release candidate passed 101 local tests, the data-free smoke test, Ruff,
bytecode compilation, CLI version/help and synthetic-demo checks, source/wheel
builds, isolated wheel installation, and dependency consistency checks.
Publication is additionally gated on the GitHub Actions Python 3.10/3.11/3.12
matrix for the release commit.

The synthetic demo is a functional workflow check only. It is not a real-data
benchmark, competition score, or adoption claim. GPU training and full-data
inference remain manual checks because the competition data and trained models
are not distributed with the project.

## Integrity boundary

SHA-256 references detect whether a linked file still matches its completed
run manifest. They are not signatures and do not establish who created or
trusted an artifact.

## Follow-up

Expanding the stable public RF API, defining a generic dataset adapter, and
evaluating optional SigMF import remain planned interoperability work. They are
not part of this release.

## External assets

Competition data, trained checkpoints, generated caches, and private test
labels are not included. Users must obtain restricted assets through their
original channel and follow the applicable terms. Dependencies retain their
own licenses.
