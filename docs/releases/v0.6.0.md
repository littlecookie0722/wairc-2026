# WAIRC-2026 v0.6.0

This release completes an interoperability and CPU reproducibility milestone
without changing the competition data or submission contracts.

## Highlights

- The reusable numerical `stft-v1` kernel is isolated in `wairc_rf` and is
  shared by the stable public API and the legacy `src.spectrogram` wrapper.
- `benchmark-fixture-v1` documents the synthetic `cpu-smoke` inputs and
  expected deterministic signature. The repository-authored fixture contains
  no raw IQ, external recordings, model weights, or private labels.
- A CPU compatibility probe checks interleaved/native-complex transform
  equality and a no-weights ResNet18 forward explicitly on CPU.

## Compatibility

This release does not intentionally change the 0..8 label mapping, interleaved
IQ parsing, missing-node semantics, `stft-v1` numerical behavior, fold
splitting, threshold search, ensemble weighting, checkpoint consumption rules,
or submission text format. Existing `src.*` entry points and public adapter,
SigMF, benchmark, and summary paths remain available. The legacy wrapper keeps
its historical 125 MHz fallback for a non-positive sample rate; the validated
public API continues to require a finite positive rate.

Synthetic metrics and the fixture signature are functional checks on generated
data only. They are not real-data benchmarks, competition scores, or adoption
claims. GPU training and full-data inference remain manual checks because
competition data and trained models are not distributed with the project.

## External assets

Competition data, trained checkpoints, generated caches, and private test
labels are not included. Users must obtain restricted assets through their
original channel and follow the applicable terms. Dependencies retain their
own licenses.
