# WAIRC-2026 v0.8.0

This release records the redistributable robustness benchmark fixture without
changing the competition data or submission contracts.

## Highlights

- `tests/fixtures/benchmark/synthetic_iq_robustness_v1.json` provides a
  repository-authored `benchmark-fixture-v1` parameter manifest for all seven
  `robustness-small` conditions.
- The fixture pins the expected deterministic `benchmark-report-v1` signature
  and is included in the source distribution. It contains no generated IQ,
  model outputs, external recordings, or private labels.

## Compatibility

The existing `cpu-smoke` fixture and benchmark profile remain unchanged. The
new JSON is an input contract for review and reproduction; generated benchmark
artifacts remain local outputs. This release does not intentionally change the
0..8 label mapping, interleaved IQ parsing, missing-node semantics, `stft-v1`,
training, inference, checkpoints, or submission serialization.

original channel and follow the applicable terms. Dependencies retain their
