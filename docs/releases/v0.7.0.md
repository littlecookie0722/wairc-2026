# WAIRC-2026 v0.7.0

This release completes a synthetic robustness and CPU execution compatibility
milestone without changing the competition data or submission contracts.

## Highlights

- The controlled `robustness-small` profile now covers seven conditions. In
  addition to the existing baseline, noise, missing-node, frequency-offset,
  timing-offset, and low-gain checks, `combined-stress` applies the documented
  noise, frequency, timing, and gain controls together.
- The data-free CPU compatibility probe now executes the no-weights ResNet18
  through both eager PyTorch and TorchScript on CPU and checks that finite logits
  remain numerically close.

## Compatibility

This release does not intentionally change the 0..8 label mapping, interleaved
IQ parsing, missing-node semantics, `stft-v1` numerical behavior, fold
splitting, threshold search, ensemble weighting, checkpoint consumption rules,
or submission text format. Existing `src.*` entry points, public adapters,
SigMF, benchmark, and summary paths remain available. The TorchScript check is
a compatibility probe only; it does not replace the competition training or
inference entry points.
