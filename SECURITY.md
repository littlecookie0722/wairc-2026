# Security Policy

This is a local/offline machine-learning pipeline, not a network service. The
main security risks are accidental disclosure of credentials or private
datasets, unsafe generated artifacts, and unauthorized security scanning.

Do not include API keys, account or organization identifiers, credentials,
private dataset locations, private test labels, or sensitive logs in issues,
pull requests, or the repository.

For a suspected security or privacy issue, do not open a public issue with
the details. Contact the repository maintainer privately through the GitHub
repository account or use a private GitHub security report when available.
Include the affected path, impact, reproduction steps that do not expose
secrets, and a proposed mitigation.
