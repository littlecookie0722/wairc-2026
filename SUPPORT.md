# Support

WAIRC-2026 is maintained as an open-source research project. The repository
does not provide a service-level agreement, but reproducible reports and
scoped proposals are welcome.

## Where to ask

- Use the bug report template for reproducible defects.
- Use the feature request template for a concrete user need.
- Use the experiment proposal template for model, preprocessing, or evaluation
  work with an explicit hypothesis and success criterion.
- Follow `SECURITY.md` instead of opening a public issue for a suspected
  vulnerability.

## What to include

Provide the smallest safe reproduction, the exact command, Python and torch
versions, operating system, device type, and relevant error output. If the
question involves an experiment, include the seed, model tag, data assumptions,
and affected compatibility boundary.

Do not upload competition data, checkpoints from unknown sources, private test
labels, credentials, account identifiers, or logs containing private paths or
personal information.
